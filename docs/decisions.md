## 2026-10-31 — 패키지 매니저는 npm 하나

- `package-lock.json` 과 `yarn.lock` 이 함께 있어 설치 결과가 갈렸다. npm 만 남겼다(`docs/DEPLOY.md` §4).

## 2026-11-14 — 결과 하단 행운의 장소·숫자

- 키오스크와 같은 행운 카드(`src/components/common/LuckyLine.tsx`)를 사주·타로·커플 결과 아래에 둔다. 응답의 `luckyPlace`/`luckyNumber` 가 둘 다 있을 때만 그린다.
- 이 페이지는 중앙 API 에서 결과를 읽으므로, 중앙 API 가 두 필드를 내려주기 전까지는 줄이 보이지 않는다(의도된 동작).
