## 2. lockfile 정리

- 기존에는 `yarn.lock` 과 `package-lock.json` 이 같이 있었고, Vercel은 이 경우 **yarn을 우선** 사용합니다
  (`vercel/vercel` build-utils `run-user-scripts.ts`: "Priority order is bun with yarn lock > yarn > pnpm > npm").
  `package-lock.json` 은 `package.json` 과 어긋나 `npm ci` 가 실패하는 상태였습니다.
- `yarn.lock` 삭제, `package-lock.json` 재생성 → **다음 배포부터 Vercel 설치가 `npm install` 로 바뀝니다.** Preview 빌드 로그로 확인하세요.
- **설치 쿨다운**: 최근 웜형 공급망 공격이 공개 후 수 시간~수일 안에 잡히는 점을 감안해, 최종 lockfile은
  `npm install --before=2026-10-24`(7일 쿨다운)로 재해석했습니다. 예외는 `follow-redirects` 1.16.2(2026-10-25 공개,
  GHSA-mrwp-f3q8-3g9p 수정판) 하나이며, 11-02 기준 7일이 지난 버전입니다.
- 모든 패키지가 `registry.npmjs.org` 에서 받아지며, 설치 스크립트가 있는 패키지는 `msw`(워커 파일 복사)와
  `unrs-resolver`(eslint-config-next 경유, 네이티브 바이너리 선택) 두 개입니다. 로컬 npm 11은 둘 다 기본 차단했고 빌드·린트는 정상이었습니다.

## 5. 이 앱 밖에서 발견한 위험 (조치 안 함 · 담당자 확인 필요)

1. **중앙서버(`ain-tarot.kr`) OpenAPI 공개** — `https://ain-tarot.kr/docs`, `/openapi.json` 이 인증 없이 열려 있고,
   스펙상 `GET /api/api_key/`(HCX·NCP API 키 목록), `POST/DELETE /api/api_key/*`, `GET/DELETE /api/kiosk/*` 에
   **보안 스킴이 선언돼 있지 않습니다.** 실제로 인증 없이 키가 조회되는지는 **호출해 보지 않았습니다**(비밀값 노출 우려).
   nginx/openresty 단에서 막고 있는지 서버 담당자 확인이 필요합니다. 막혀 있지 않다면 최우선 조치 대상입니다.
2. **GitHub 저장소가 public** (`ain-dev/ain-tarot-result`, `private: false`). 현재 레포에 비밀값은 없지만,
   공개 의도인지 확인 필요. (`.env*` 커밋 금지 유지)
3. CVE-2026-96889 류 이미지 최적화 취약점과 관련해, Vercel에서는 `next/image` 최적화를 Vercel 이미지 서비스가 수행하므로
   앱의 `sharp` 와 무관할 수 있으나 **1차 출처로 확인하지 못했습니다.** 업그레이드로 어느 쪽이든 해소됩니다.
